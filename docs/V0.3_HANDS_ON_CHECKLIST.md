# EQ Library v0.3 Hands-On Validation

Use the latest **signed beta** artifact from `eq-library-community-v0.3`. Do not use the ordinary debug APK for the upgrade test.

This is the final Pixel 9 / TRN Black Pearl checkpoint before v0.3 can move toward `main` or public release. PR #3 stays draft and unmerged until this checklist passes.

## STOP conditions

Stop testing and report the step if any of the following occurs:

- Android refuses to install the signed v0.3 APK over the installed v0.2.0 app or requires uninstalling first.
- Existing v0.2.0 selections, saved EQ state, or app-owned export records disappear unexpectedly after upgrade.
- The app crashes, repeatedly hangs, or cannot reopen after upgrade.
- Choosing an output hides otherwise valid curves from EQ Library.
- Selecting/saving an EQ creates a device export without an explicit Export action.
- A cleanup action deletes a file the app does not own.
- Black Pearl Flash changes global DAC volume or any non-EQ DAC setting.
- Black Pearl Flash writes before the confirmation step.
- A profile labeled Exact is materially changed by its output conversion.
- The same acoustic tuning appears as duplicate catalog profiles when it should be one canonical tuning with provenance references.
- Historical revisions are silently replaced rather than remaining selectable.

If none occur, continue through the checklist.

## 1. Capture v0.2.0 state before upgrade

Before installing v0.3, open the currently installed v0.2.0 app and note at least one existing item that can be checked after upgrade:

- one saved headphone/profile selection, if present;
- one favorite/personal EQ, if present;
- one app-owned exported file, if present.

Do not clear app data and do not uninstall v0.2.0.

## 2. Install v0.3 in place

1. Install the latest signed `EQ-Library-v0.3.0-beta-<sha>.apk` over v0.2.0.
2. Confirm Android performs an update rather than installing a separate app.
3. Open EQ Library and confirm the primary navigation is **My EQs | EQ Library | Settings**.
4. Confirm existing v0.2.0 headphone selections are present under the UAPP/ToneBoosters output.
5. If a v0.2.0 favorite/personal EQ existed, confirm it also migrated to the UAPP/ToneBoosters My EQs collection rather than appearing automatically under every output.

**Pass:** v0.3 installs in place and existing user state is preserved under the UAPP output context.

## 3. Output selector must not filter the library

1. Open **Settings → Outputs** and enable at least UAPP/ToneBoosters and TRN Black Pearl. Optionally enable Universal PEQ, Poweramp, and Wavelet.
2. Return to **EQ Library** and search for a known headphone such as HIFIMAN Edition XS.
3. Note the available EQ profiles.
4. Switch the top output selector between UAPP/ToneBoosters and Black Pearl.
5. Confirm the same usable canonical profiles remain visible/selectable.
6. Confirm only their output status changes as appropriate: **Exact**, **Optimized**, or **Not exportable**.

**Pass:** output is operating context, never a catalog-visibility filter.

## 4. Browse, provenance, revisions, and Unverified behavior

1. Open a headphone with multiple sources/revisions, using Edition XS when practical.
2. Confirm source/creator information and Source links are visible where available.
3. Confirm an older materially different revision can remain available through history rather than being overwritten by Latest.
4. If an Unverified community profile is available, confirm it is labeled **Unverified** / not independently verified and remains manually selectable.
5. Confirm an Unverified profile is not silently added merely because **Automatically include new EQs** is ON.

**Pass:** provenance, revision history, and trust state are distinct from output capability.

## 5. Output-specific My EQs

1. With UAPP/ToneBoosters active, save/select at least one headphone EQ.
2. Save/favorite a second EQ or import a personal PEQ if practical.
3. Open **My EQs** and confirm the saved entries appear under **Headphones**.
4. Switch active output to Black Pearl.
5. Confirm UAPP-only selections do not automatically become Black Pearl selections.
6. Add at least one EQ while Black Pearl is active and confirm it appears in Black Pearl My EQs.
7. Switch back to UAPP and confirm the UAPP collection is unchanged.
8. If General EQs are available, add one under **EQ Library → General EQs** and confirm it appears in the active output's **General EQs** section only.

**Pass:** My EQs membership is independent per output without duplicating or mutating canonical source data.

## 6. General EQ browsing

1. Open **EQ Library → General EQs**.
2. Exercise **All**, **Sound**, **Genre**, and **Utility** filters where populated.
3. Confirm General EQs are standalone presets and are not silently layered onto a headphone EQ.
4. Confirm source/intent wording does not imply a genre preset is objectively correct merely because of its category.

**Pass:** General EQ classification and saving are understandable and independent from headphone correction.

## 7. UAPP/ToneBoosters export regression

1. Select **UAPP / ToneBoosters** as the active output.
2. Open a saved headphone profile in My EQs.
3. Confirm its status is Exact/Optimized/Not exportable as appropriate.
4. For an exportable profile, use **Export** explicitly.
5. Confirm the expected XML is created in the chosen SAF destination and imports successfully in UAPP/ToneBoosters.
6. Confirm preamp/headroom, filter count, frequencies, gains, Q values, and supported filter types correspond to the selected source.
7. For a source over 10 bands, confirm UAPP is labeled Optimized and only the first 10 source-priority bands are used.
8. Return to My EQs after a successful current export and confirm the per-item Export action clears/disappears when current.
9. If practical, delete that app-owned exported file outside the app, return/reopen My EQs, and confirm Export becomes available again.

**Pass:** UAPP export remains explicit, deterministic, source-preserving, and currentness-aware.

## 8. Export All and ownership safety

1. Ensure at least two exportable EQs in the active My EQs collection need export.
2. Confirm **Export all** is available and use it.
3. Confirm it writes/updates only the active output's pending app-managed presets.
4. After all exportable items are current, confirm Export All no longer presents itself as pending work.
5. Place or retain an unrelated file in the destination if practical.
6. Use an app cleanup/remove-with-files action for an EQ Library-owned item.
7. Confirm the owned file is removed while the unrelated file remains untouched.

**Pass:** export currentness and cleanup are scoped to app-owned deterministic files.

## 9. Black Pearl connection UX

1. Select **TRN Black Pearl** as the active output.
2. In Settings, enable **Direct Flash**.
3. Open **My EQs** with the DAC disconnected.
4. Confirm the top control shows a prominent red **Connect to DAC** state/action.
5. Confirm per-row **Flash** is visible but disabled while disconnected.
6. Connect the TRN Black Pearl to the Pixel 9 and use **Connect to DAC**.
7. Approve Android USB permission if requested.
8. Confirm My EQs reports the DAC as connected using the green connected state.

**Pass:** connection controls exist in My EQs only and do not interfere with file Export.

## 10. Black Pearl direct Flash — EQ-only safety

Choose a Black Pearl profile that the app reports as exportable/flashable. Prefer a simple profile first.

1. Record the Black Pearl's current global volume and any other DAC setting you can easily observe.
2. Tap **Flash** on the selected My EQs row.
3. Confirm a **Flash to Black Pearl?** confirmation appears before any write.
4. Cancel once and confirm nothing changes.
5. Start Flash again and confirm.
6. Confirm the app reports **Flash successful** when the write completes.
7. Confirm the EQ was written to the DAC's currently active EQ slot.
8. Confirm global DAC volume did **not** change.
9. Confirm unrelated DAC settings were not changed.
10. Audibly/visually confirm the flashed EQ is active where the Black Pearl exposes that state.

**Pass:** Direct Flash changes only EQ state on the current slot and does not manage unrelated DAC controls.

## 11. Black Pearl filter types and limits

Use source profiles that exercise the available cases when practical.

1. Flash/export a profile containing Peak filters and confirm it succeeds when values are in range.
2. Flash/export a profile containing a native Low Shelf and confirm the shelf remains a Low Shelf rather than being replaced with synthetic peaking filters.
3. Do the same for a High Shelf if a suitable profile is available.
4. For a source over 10 bands, confirm Black Pearl reports **Optimized**, warns that only the first 10 source-priority bands are used, and does not alter the canonical source record.
5. For a profile requiring nonzero source preamp or generated headroom, confirm Black Pearl reports **Not exportable/Not flashable** rather than changing global DAC volume.

**Pass:** native corroborated filter types are preserved, the 10-band limit is explicit, and preamp is never implemented through hidden volume changes.

## 12. Offline / last-known-good behavior

1. With a usable catalog already loaded, put the phone offline.
2. Relaunch EQ Library.
3. Search/open a previously available headphone and profile.
4. Confirm the saved catalog remains usable.
5. Trigger Refresh now if practical and confirm failure is non-destructive and the saved library remains available.
6. Restore network access.

**Pass:** a network outage never empties or blocks the last-known-good library.

## 13. Restart and basic accessibility check

1. Fully close and reopen EQ Library.
2. Confirm the active output and its My EQs collection persist correctly.
3. Confirm no unexpected duplicate/missing state appeared.
4. Increase Android font size and confirm the primary nav, output selector, My EQs actions, and Settings remain usable without clipped critical actions.
5. With TalkBack if practical, confirm Connect, Export, Flash, Remove, output selector, and profile checkbox controls have understandable labels.

**Pass:** the candidate remains stable across restart and basic accessibility scaling.
