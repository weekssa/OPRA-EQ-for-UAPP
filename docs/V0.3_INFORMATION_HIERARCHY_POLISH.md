# EQ Library v0.3 — Information hierarchy polish

This addendum records the user-approved final information-hierarchy cleanup for PR #4. It supplements `docs/CHATGPT_PROJECT_RUNBOOK.md` and `docs/V0.3_RELEASE_POLISH_PLAN.md`; later explicit user decisions remain authoritative.

## Goal

EQ Library has evolved from an OPRA-centered browser into a source-agnostic canonical EQ library. Primary screens therefore prioritize the user's task rather than project/source explanation.

Principle:

`primary screens = find/use/manage EQs`

`Settings/About = project information, contribution, attribution, privacy, licensing`

Moving attribution does not reduce attribution requirements. Individual EQ creator/source provenance remains available with the EQ, and source/project attribution remains accessible from Settings.

## EQ Library root

### Headphones

The Headphones root must be task-focused:

1. Headphones / General EQs tabs
2. Search headphones
3. Manufacturer list or search results

Do not reserve the first viewport for:

- an OPRA logo/banner;
- an OPRA project description;
- the general explanation that EQ Library combines sources;
- a Submit an EQ source action.

The active-output selector remains global operating context. Exact / Optimized / Not exportable information belongs where it is actionable rather than in a permanent explanatory banner.

Per-profile Source links and provenance remain available where they help the user evaluate a specific EQ.

### General EQs

The General EQ tab similarly prioritizes search, Sound/Genre/Utility filters, batch controls, and presets. Do not add a large ParaEQ or other source banner. Source attribution remains attached to the preset/details and in Settings → Data sources & attribution.

## Settings root

Keep the existing functional Settings areas, then use compact navigation rows rather than a long inline About/legal wall.

### Help & contribute

Provide one row:

**Feedback & EQ submissions**

Description:

`Report a problem, suggest an improvement, or submit an EQ source.`

This opens the repository's GitHub issue chooser so bug reports, feature/feedback requests, and EQ-source submissions share the same project interaction entry point. It replaces the primary-screen Submit an EQ source action.

### About

Provide compact rows:

- **About EQ Library** — version, local/privacy statement, source code, licensing, independence/non-endorsement.
- **Data sources & attribution** — OPRA, AutoEq, ParaEQ, creators, repositories, and public communities.

Both are in-app Settings subpages. Android/visible Back returns to Settings root before normal root Settings Back returns to My EQs.

## About EQ Library

Include:

- installed app version;
- concise statement that selections/settings/generated preset state/conversion remain local, no account is required, and the app contains no analytics/telemetry;
- Source code link;
- Privacy link;
- Apache-2.0 project license statement;
- Black Pearl independent observable-protocol/reference statement;
- non-affiliation/non-endorsement statement.

Do not turn the page into source-specific branding.

## Data sources & attribution

Open with source-agnostic wording:

> EQ Library combines attributed EQ data from OPRA and other qualified public sources. Creator and original-source information is preserved with each EQ whenever available.

Then present source-specific attribution compactly.

### OPRA

Describe OPRA as an open community-maintained headphone database and **one source used by EQ Library**. Keep links to the OPRA project and OPRA data license. Do not say that all headphone/EQ data comes from OPRA.

### ParaEQ

Credit the MIT-licensed ParaEQ built-in definitions as the initial General EQ source. Preserve the source-authored preset labels/coefficients and the distinction between missing source preamp and EQ Library-generated safety headroom.

### Other attributed sources

Explain that the library can also contain AutoEq, creator, repository, and public-community EQ profiles and that available creator/source provenance is preserved per profile.

The large OPRA logo is not required on normal app navigation. If source artwork is used in the future, it belongs only in a secondary attribution context and must not imply that one source is the product identity.

## Focused Pixel 9 acceptance

Before public v0.3.0 release, confirm on the final exact-head signed APK:

1. EQ Library → Headphones goes from Search directly into manufacturer/search results; no large OPRA attribution block or Submit an EQ source action occupies the browse root.
2. General EQs remains preset/task focused and does not replace the removed OPRA block with another large source banner.
3. Settings contains Help & contribute → Feedback & EQ submissions and it opens the GitHub issue chooser.
4. Settings contains About EQ Library and Data sources & attribution as separate subpages.
5. About EQ Library shows accurate local/privacy, license, source-code, independence/non-endorsement information.
6. Data sources & attribution accurately describes OPRA as one source, credits ParaEQ, describes additional attributed source lanes, and retains OPRA project/data-license access.
7. Back from either Settings subpage returns to Settings root; root Settings Back continues to My EQs.
8. Individual profile/preset Source links remain available where applicable.

This is presentation/information architecture only. It does not change canonical catalog data, source ingestion, Hide/Unhide, selection, export, or Black Pearl protocol/DSP behavior.
