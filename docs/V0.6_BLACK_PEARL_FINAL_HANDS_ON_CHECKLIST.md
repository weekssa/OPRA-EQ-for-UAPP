## Safety preparation

Before any EQ write:

1. Stop playback.
2. Reduce DAC/playback volume to a conservative level.
3. Disconnect headphones/IEMs or mute downstream amplification when practical for the first write of each transaction type.
4. Use only known, ordinary in-range EQ values for the release smoke; do not deliberately create high boosts or extreme volume conditions.
5. Do not test firmware, bootloader, identity, raw-register, or unqualified DEVICE write paths.
6. If the app reports a mismatch, stale baseline, connection loss, or incomplete Apply, stop and re-read actual hardware before attempting another write.
