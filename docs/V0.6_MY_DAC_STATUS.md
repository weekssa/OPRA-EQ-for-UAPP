## USB audio mode

- **UAC 1.0/2.0 current-mode detection is implemented** from standard USB AudioControl descriptors and appears under DEVICE -> USB / System.
- UAC mode remains **read-only** because no exact Black Pearl software switching command has been established.
- Unknown, malformed or conflicting descriptor evidence produces Unknown rather than a guessed mode.
- Unknown UAC mode does not invalidate an otherwise complete normal DEVICE-state read.
- Review of `Matr1x01/trnBlackPearlEq@f289230...` adds independent corroboration for the known normal-control command map but contains no software UAC command.
- No speculative probing or borrowed related-device command will be used.
