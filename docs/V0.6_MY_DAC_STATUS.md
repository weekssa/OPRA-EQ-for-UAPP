## Implemented v0.6 My DAC behavior

The approved My DAC core is implemented, including:

- supported-DAC recognition and session-sticky My DAC navigation;
- current/stale USB-session handling;
- Black Pearl native EQ readback, deterministic matching, response visualization, editor, Review -> Apply -> verified readback, Save DAC EQ, Change EQ, and Reset EQ to flat;
- capability-driven DEVICE presentation for firmware, DAC filter, gain mode, amp topology, microphone gain, balance, and playback/global level;
- a typed DEVICE transaction contract that requires a current expected session, takes a complete fresh baseline, writes only the requested control, performs complete readback, verifies the requested value, rejects unrelated-state changes, and never invokes the generic Save-to-Flash command;
- local staging and explicit Current/New review before writes;
- no silent retry after USB-session replacement and no cached-state replay on reconnect;
- no requested value presented as current before readback verification.

The product accent is the approved TOPPING-reference blue `#257BFF`, while semantic warning/error/success colors remain semantic.

## Consolidated hands-on scope

The single physical round uses only small reversible changes, in this order:

1. Balance: Center -> `-1 dB` -> Center.
2. Microphone gain: `0 dB` -> `-1 dB` -> `0 dB`.
3. Amplifier topology: `CLASS AB` -> `CLASS H` -> `CLASS AB`.
4. Gain mode: `HIGH` -> `LOW` -> `HIGH`.
5. Playback/global level, last because it is level-sensitive: raw `512` / `+2.00 dB` -> raw `384` / `+1.50 dB` -> raw `512` / `+2.00 dB`.
6. One independent-controller read-only comparison after all values are restored; never use Save to Flash.
7. One disconnect/reconnect freshness check and final complete EQ Library read.

Each control must independently pass its requested change, complete readback, unrelated-state preservation, and restoration. Any error, mismatch, stale session, disconnect, transfer failure, or unexpected unrelated-state change stops further writes until investigated; do not retry blindly.
