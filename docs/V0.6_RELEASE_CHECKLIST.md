The baseline comparison includes the independent controller's `Volume 63%` presentation. Its maintained source maps percentage linearly over the same raw range; EQ Library's raw `512` maps to approximately `62.745%`, so the rounded `63%` and EQ Library's `+2.00 dB / raw 512` are reconciled as two presentations of the same underlying playback register.

The repeated-read gate passed on 2026-09-13: the project owner explicitly performed three consecutive qualification reads with no DAC setting changes, and all three remained **Current session read** with the same seven values.

The fresh-read gate also passed on 2026-09-13: the project owner changed only the DAC reconstruction filter externally, confirmed EQ Library reported the changed hardware value with unrelated fields unchanged, then restored `Fast-PC` externally and confirmed EQ Library freshly reported the restored baseline.

The disconnect stale-state gate passed on 2026-09-13: after a successful current read, the Black Pearl was physically unplugged while EQ Library remained open; My DAC stayed session-visible, the connection became **Disconnected**, retained values were no longer presented as current, and a current hardware read could not succeed while disconnected.

Passing this section qualifies read semantics only. It does not authorize new DEVICE writes.
