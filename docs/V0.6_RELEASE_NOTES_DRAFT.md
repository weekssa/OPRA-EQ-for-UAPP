## What's new

### My DAC

EQ Library can now recognize supported DACs and open a dedicated **My DAC** area without changing your separate active output in My EQs / EQ Library.

When a supported DAC is recognized, navigation becomes:

**My EQs · My DAC · EQ Library · Settings**

My DAC stays available for the current app session after disconnect so the app can clearly distinguish **current hardware** from a **Last read** instead of making navigation jump.

### Read the actual Black Pearl EQ

For TRN Black Pearl, My DAC reads the native hardware EQ and shows:

- current/Last-read state;
- Flat, exact saved match, modified-known, ambiguous exact, or Unknown identity state;
- active slot and filter count;
- current playback/global-gain context;
- a combined parametric response graph;
- exact native differences when a known saved EQ has been modified through EQ Library.

EQ identity is conservative: cold-start similarity is never treated as source attribution, and ordinary playback volume is not used to invent an EQ match.

### Change EQ from My DAC

**Change EQ** uses the Black Pearl-specific My EQs collection and shows whether each saved EQ is **Exact**, **Optimized**, or **Not suitable** for the device.

Choosing an EQ opens a review first. It never writes hardware merely because you selected a row.

### Edit EQ on the device

The Black Pearl editor starts from a fresh verified hardware read and provides:

- tap-to-select response graph markers;
- exact filter type, frequency, gain, and Q editing;
- All Bands view;
- live deterministic combined-response preview;
- headroom assessment from the complete planned response;
- separate device-limit, caution, and headroom warnings;
- Review before Apply;
- hardware readback verification after Apply.

Dragging the graph never changes hardware. Local edits remain local until explicit Review -> Apply.

### Headroom-aware Apply

EQ Library evaluates the complete planned response rather than simply looking for the largest positive band gain. When additional safe attenuation is needed, the editor makes that requirement visible before a write.

For Black Pearl, EQ Library continues to distinguish its tracked EQ safety adjustment from the DAC's ordinary playback volume and preserves safe write ordering.

### Save DAC EQ

Unknown or known-modified Black Pearl hardware state can be captured as a local **Personal EQ**.

Captured EQs preserve native filter values and device provenance. You can associate a capture with a real saved/library headphone or intentionally leave it unassociated. EQ Library does not invent a creator/source association, and an exact existing saved match is linked rather than duplicated.

### Reset EQ to flat from My DAC

My DAC now includes the already-qualified Black Pearl **Reset EQ to flat** workflow as a secondary confirmed action. It replaces the hardware EQ with the verified flat state while preserving the established safe tracked-gain behavior rather than arbitrarily resetting listening volume.

### DEVICE architecture and read-only qualification

v0.6 adds the capability-driven DEVICE foundation. Unsupported/unqualified controls are not shown merely because another controller exposes something with a similar name.

For Black Pearl, the current qualification surface can read firmware/version, DAC reconstruction filter, gain mode, amplifier topology, microphone gain, balance, and playback/global gain from one verified current session.

**Important:** passing read-only qualification does not automatically authorize write controls. New DEVICE writes remain hidden until each exact command/range/readback/persistence/safety path is separately qualified.

## Safety and privacy

- No account, analytics, telemetry, or cloud backend is added.
- My DAC state stays local.
- Connecting a DAC does not silently change your active output.
- Reconnect never pushes cached device values back to hardware.
- Requested editor state is not reported as current until verified hardware readback succeeds.
- Firmware/bootloader/cross-flash writes and raw register/USB-identity mutation are not exposed.
