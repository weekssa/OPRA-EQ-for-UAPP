## Disposition terms

- `PASS (...)` states the evidence type and scope. `PARTIAL` means the full row is not established. `NOT RUN` means it has not been performed.
- `NOT APPLICABLE` is limited to a conditional enhancement not implemented. `DEFERRED` applies only to SHOULD enhancements and does not waive a MUST.
