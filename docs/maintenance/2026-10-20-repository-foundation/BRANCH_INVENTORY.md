## Assessment method and limits

Branch tips, dates, subjects, ahead/behind counts, ancestry and `git cherry` patch-equivalence were measured from fetched refs. Open PR descriptions and current public release records were checked separately. A unique patch count means changes are not represented by an equivalent patch on current `main`; it does not establish that the branch should be merged. Several branches contain experiments, older releases, task ledgers, signed candidates or catalog data. Review exact diff and evidence/PR relationships before any future integration. Do not use age, branch name or a differing commit hash alone to delete or merge a branch.
