The pristine v0.7.1 API 26 failure was reproduced on a freshly wiped AVD with `dalvik.vm.heapgrowthlimit=48m`. `CanonicalCatalogRepository.loadSnapshot()` first buffered the 19,375,344-byte canonical catalog as a `String`. Streaming fixed that allocation, but an early three-second smoke falsely passed; longer cold launches exposed additional pressure from eager lookup indexes, profile alias resolution, band normalization, and acoustic deduplication. The current implementation uses lazy catalog indexes and band projections, compact collision-checked acoustic fingerprints, fixed-precision formatting with exact fallback checks, and background catalog projection. One exact-commit attempt logged an OOM while UIAutomation dumps collided; the serialized clean rerun passed. The successful committed-source run and earlier local smokes are stored separately. Exact PR CI x86_64 remains required.
