# OPRA EQ for UAPP v0.1.0

This is the first public development release of **OPRA EQ for UAPP**.

The app downloads the OPRA runtime catalog, lets you choose compatible parametric EQ profiles, converts them locally to USB Audio Player PRO / ToneBoosters XML, and exports the resulting presets through Android's system folder picker.

## Highlights

- Local Manufacturer → Model browsing and headphone search over the cached OPRA catalog.
- **My Headphones** library with exact profile selections, explicit exclusions, and optional automatic inclusion of future compatible OPRA profiles.
- Native Kotlin OPRA → UAPP/ToneBoosters conversion; Python is not bundled in the APK.
- Deterministic XML generation preserving OPRA preamp, frequency, gain, Q, profile order/priority, creator/details, and attribution.
- Explicit handling of ToneBoosters' 10-band limit: the first 10 OPRA-priority bands are used and the limitation is shown in the app.
- Android Storage Access Framework export without broad storage permission.
- Offline Browse/Search after the first successful catalog sync.
- Manual Refresh plus approximately daily catalog checks for managed-headphone changes.
- Local-only selections/settings/conversion with no account, analytics, or telemetry.
- Appearance, accessibility, OPRA attribution, privacy, and update-check surfaces validated on a Pixel 9.

## Conversion compatibility

The currently proven mappings are:

- `peak_dip`
- `low_shelf`
- `high_shelf`

OPRA profiles containing unsupported filter mappings or required acoustic values that cannot be represented safely remain discoverable as **Not compatible** and are never silently approximated, clamped, or dropped.

## Install

Download `OPRA-EQ-for-UAPP-v0.1.0.apk` from the Assets section of the GitHub Release and install it on Android 8.0 / API 26 or newer.

Because this release is distributed directly from GitHub rather than an app store, Android may ask you to allow installation from the browser or file manager you use to open the APK. The app itself does not request package-install permission and does not silently install updates.

Future GitHub releases are intended to use the same Android release-signing identity so normal in-place updates remain possible.

## Privacy and attribution

The app ships with zero headphone profiles. It retrieves the OPRA runtime catalog from `opra.roonlabs.net`, caches the validated catalog locally, and may read public GitHub Release metadata to check for app updates. Headphone selections, settings, generated presets, and conversion stay on the device.

OPRA-derived data is attributed under CC BY-SA 4.0. Individual EQ creator/source information is preserved where OPRA provides it. OPRA EQ for UAPP is not affiliated with or endorsed by OPRA, Roon Labs, USB Audio Player PRO/UAPP, ToneBoosters, or headphone manufacturers.

See the repository `PRIVACY.md`, `DATA_LICENSE.md`, and `NOTICE` files for details.

## Validation

The Android implementation passed the automated unit/lint/build gate and hands-on Pixel 9 testing covering fresh catalog acquisition, offline reuse, Browse/Search, My Headphones, XML export and cleanup, UAPP/ToneBoosters preset import, appearance, large text, TalkBack, privacy, and attribution.

The permanently signed `v0.1.0` candidate then passed an additional Pixel 9 release-build smoke test before publication. The published workflow rebuilt the same frozen release commit, verified the same pinned signing certificate, and published the signed APK plus SHA-256 and `apksigner` verification assets.
