## Included (proven)

1. EW300 0–60 device volume mapped to register 0x66, both stereo bytes, readback verified.
2. UAC1 microphone mute with GET_CUR verification and restore.
3. Current sample-rate readout from the UAC1 endpoint.
4. Runtime Apply versus explicit Save, with a single Save per explicit action.
5. EQ Library / My EQs Flash to the EW300 through the existing route
   (flashManagedProfile / flashSavedEq / flashGeneralEq → flashHardwareProfile → flashEw300Profile
   → HardwareEqRepository.flashEw300 → Ew300Flasher.flash). No second flasher or protocol path.
6. Five-Peak optimizer fallback for any profile outside the experimental native-shelf envelope,
   reported as "Optimized"; shelves are never silently dropped.
7. Read-only UAC status (UAC 1.0, no mode switch claimed).
8. About: model, firmware state, USB identity, validation class.

## Excluded

- Headset-remote switch: chip-limited on KT0211L; no USB/HID control exists.
- UAC mode switch: KT0211L exposes UAC 1.0 only.
- Native Low/High Shelf product controls: acoustics unmeasured. The editor chips, shelf A/B
  controls, and research setup panel are compiled off (EW300_ENGINEERING_CONTROLS = false,
  EW300_SHELF_EDITOR_ENABLED = false) and exist only in the local ew300Engineering variant.
- Ellyn/DCR tuning, firmware update, bootloader, erase, calibration, recovery, LFE/crossover
  inventions.
- Any claim of full JA11 parity.

## Native-shelf policy in this build

EW300_SHELF_EDITOR_ENABLED = false means the flasher runs Peak-only: every profile, including one
carrying native shelf bands, is fitted to the five-band bank and reported as Optimized. Native
type 3/4 writes remain available only in the engineering variant, where the flag is on and the
readiness docs already record the byte-level evidence and the unmeasured acoustics.

## Library migration

Production (com.weekssa.opraeqforuapp) and the prototype are separate packages. Catalog-derived
managed profiles migrate by re-selecting the same canonical identity in EQ Library, which preserves
name, filter values, provenance, and the EW300 output association. Production's EW300 output is
hardware-only and offers no file export, so Personal or General EQs would need a real export path
that does not exist yet; a profile edited away from the catalog original would not transfer this way.
The prototype does not copy the production database and never claims a complete library migration.

4. My EQs → AFUL Explorer → LoboNautics → Flash. Expect "Optimized · 8 → 5 bands", one Save, the

Rollback: uninstall the prototype package; it never writes firmware or persistent device identity.


## Device surface (UX correction)

The DEVICE page matches the JA11 device-settings layout and uses the shared production components:

- DeviceOperationStatusHeader with the current state and one Refresh action.
- Audio: Device volume (0–60) and Startup settings only when the saved state is known.
- USB & System: Current sample rate and USB Audio Class, read-only.
- About: Model, USB identity, Filters ("Five-band Peak, verified"), Device limitations. Firmware
  appears only when it has been read.

Removed: a duplicate Output gain row for the same 0x66 control, the Equalizer and Connection rows,
the Headset remote row, the Read USB audio button, raw descriptor and GET_CUR prose, the
Experimental features row, and the native-shelf engineering section.

## Microphone

The mute request is accepted by the device and verifiable as a UAC value, but no capture path reaches
it from this Pixel and the owner heard no difference in either position. The toggle and the
Microphone section are removed; About carries the limitation that no effect on captured audio has
been measured.


## Pixel qualification (candidate 12974c73)

The corrected DEVICE page and the library Flash were checked on the Pixel 9: one Save wrote AFUL
Explorer — LoboNautics through the five-Peak fallback with an exact readback, and one restoration
Save returned Flat at 0.0 dB. No listening test was run and no firmware or identity write occurred.


## Pixel verification (polished candidate 1995927d)

Startup settings offers Save and persisted across an unplug/replug; USB audio class now lives in
About; the volume dialog uses the one-line copy. Open finding: a Reset to flat on its own did not
survive a disconnect, while reset plus an explicit Save did.


## Context bar

My EQs and EQ Library show the active target followed by the target DAC's state and a single action:
Connect, Open Settings (Direct Flash off), or Open My DAC. The card body opens My DAC; the action is
its own 48 dp button. A live session or remembered readback keeps the block visible when the target
is an app. Settings is unchanged and shows no bar.
