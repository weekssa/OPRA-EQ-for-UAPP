# EQ Library v0.11.0

**Status: stable public release.** v0.11.0 is returned by GitHub `releases/latest`; v0.10.0 is the
previous stable release.

- Package: com.weekssa.opraeqforuapp
- Version: 0.11.0 / versionCode 23
- Installs over v0.10.0, v0.9.0 and the beta lines and keeps local app data
- No Google Play account, cloud account, analytics or telemetry

## Highlights

### SIMGOT EW300 DSP support

My DAC now covers the SIMGOT EW300 in the same JA11-style device layout:

- Device volume 0-60 on register 0x66, both stereo bytes, readback after every change.
- Current sample rate read from the UAC endpoint.
- Runtime edits versus one explicit Save, with Save committing EQ and output gain together.
- About carries model, USB identity and the device limits.

The microphone mute request is not offered. The device accepts it, but no captured audio changed
on the tested phone, so About states the limitation instead of showing a switch that does nothing.

### My EQs and EQ Library context bar

Both audio surfaces show the EQ target, that target's device state, and one action: Connect,
Open My DAC, or Open Settings when Direct Flash is off. The bar keeps speaking for the last hardware
target, so an unplugged DAC reads "No DAC attached" instead of silently disappearing.

### Library backup and restore

Settings -> Library gains Backup and Restore. One JSON file carries your saved EQs and General EQs,
written from the stored rows and read back without replacing anything you already have. This is how a
library moves between the public app and a separately installed prototype build.

### Flash reliability and session truthfulness

- A flash that cannot read the device now retries the empty register once before refusing, so a
  single missed read no longer aborts a transaction. Writes and Save stay single-shot.
- A session that answered and then stopped answering reports "Connection issue" with Connect, which
  re-opens the device instead of repeating a read that just failed. A failed first read after Save
  keeps Open My DAC, because that is a replacement session settling.

## Not included

- Native Low/High Shelf controls. The protocol path is qualified byte for byte, but the acoustics are
  unmeasured, so the controls stay compiled off rather than shipping an unverified claim.
- Headset-remote switching and UAC mode switching: chip-limited on this device.
- Firmware update, bootloader, erase or calibration. No path is exposed.

## Upgrade and install

- In-place upgrade from v0.10.0 and earlier stable or beta builds keeps My EQs, imports and settings.
- Clean install needs no account and no Google Play services.
- The APK is signed with the project permanent release key; the public certificate fingerprint is
  published in `release-signing-cert.sha256`, and a checksum sidecar ships with the release.

## Evidence and limits

- Qualified on one Pixel 9 with a SIMGOT EW300: volume, sample rate, Apply and Save, a library flash
  with one Save and exact readback, one restoration Save, and reset persistence across a power cycle.
- The context bar states and the library backup round trip were verified on the same device.
- No listening test was run and no acoustic claim is made anywhere in this release.
- The 0-60 volume mapping is an EW300 mapping, not a FiiO JA11 command.
