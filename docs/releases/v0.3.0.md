# EQ Library v0.3.0

This release completes the v0.3 EQ Library foundation: a source-agnostic canonical EQ library, output-specific saved collections, safer Android export ownership, and optional direct TRN Black Pearl flashing.

## Highlights

- Adds the global output context used by **My EQs** and **EQ Library**. Initial outputs include UAPP/ToneBoosters, TRN Black Pearl, Universal Parametric EQ, Poweramp/Poweramp Equalizer, and Wavelet.
- Keeps the canonical library visible regardless of output. Each EQ is evaluated separately as **Exact**, **Optimized**, or **Not exportable** for the active output.
- Adds output-specific **My EQs** collections so the presets saved for one output do not silently become selections for another.
- Adds the multi-source canonical catalog foundation for OPRA, AutoEq, qualified creator/repository data, public community EQs, provenance, verification state, deduplication, and immutable acoustic revisions.
- Adds **Headphones** and **General EQs** library areas, including Sound, Genre, and Utility general-preset categories where source intent supports them.
- New headphones start with no profiles selected and automatic future-profile inclusion OFF, so additions are explicit.

## Export and file ownership

- **Add/Save** now performs the initial export for the active output. Normal **Export** / **Export all** actions are recovery controls and remain hidden while expected app-managed files are current.
- Export ownership follows stable output/product/profile identity and the exact Android Storage Access Framework document URI returned for the app-created file, rather than depending on exact filename spelling.
- If a document provider adjusts or normalizes the requested filename, EQ Library keeps and tracks the successful file instead of deleting it and leaving the preset stuck in recovery.
- Same-name unowned files are never overwritten or deleted. EQ Library creates a stable separately owned fallback file instead.
- Internal same-name presets receive stable identity-derived filenames so both can remain exportable.

## TRN Black Pearl Direct Flash

- Adds optional **Direct Flash** from My EQs when TRN Black Pearl is the active output and Direct Flash is enabled in Settings.
- Reads the DAC's current EQ slot and writes the selected EQ using the independently implemented Black Pearl HID protocol.
- Preserves native Peak, Low Shelf, and High Shelf filters and writes all 10 hardware bands, flattening unused bands so stale filters do not remain active.
- Applies the selected profile's required source preamp / generated headroom using the Black Pearl global playback-gain command when representable.
- Replaces the previous EQ Library-applied gain adjustment instead of stacking attenuation across repeated flashes; a later 0 dB profile can restore the prior EQ Library adjustment.
- Keeps unrelated DAC controls outside the Flash path.
- Values outside the previously validated approximately -10 dB..+10 dB per-filter range are preserved exactly when protocol-encodable and require an explicit caution / **Flash anyway** confirmation rather than being silently clamped.

The signed v0.3 candidate was validated on a Pixel 9 with a TRN Black Pearl. The focused Edition XS Altruistic-Farmer275 test confirmed the `13,500 Hz / -11.9 dB / Q 4.0` filter could be exported unchanged, cancelled before writing, and then flashed through the explicit caution path without the app clamping it to -10 dB.

## UAPP / ToneBoosters

- Keeps the established Kotlin conversion behavior and deterministic ToneBoosters XML generation.
- Preserves OPRA/source preamp, frequency, gain, Q, source order/priority, creator metadata, details, and attribution.
- ToneBoosters remains limited to 10 bands; profiles over the limit use the first 10 source-priority bands with an explicit Optimized status while the complete canonical source remains local.

## Install / upgrade

Download the signed `OPRA-EQ-for-UAPP-v0.3.0.apk` asset from this GitHub Release and install it on Android 8.0 / API 26 or newer.

The application ID remains `com.weekssa.opraeqforuapp`, versionCode is 3, and the release uses the same permanent Android signing identity as prior GitHub releases. Existing installations should upgrade in place without uninstalling or clearing app data.

## Validation

The exact signed beta candidate passed Android unit tests, lint, debug/release assembly, catalog/currentness validation, priority-community validation, CodeQL, APK alignment, pinned signing-certificate verification, and Pixel 9 / TRN Black Pearl hands-on testing. Hands-on coverage included upgrade/state preservation, output-specific collections, initial Add/Save export, recovery-only Export behavior, provider-adjusted filenames, ownership-safe collision handling, UAPP/ToneBoosters regression, Black Pearl connection and active-slot behavior, playback-gain replacement/non-stacking behavior, native filter types, the 10-band path, and the explicit -11.9 dB caution/Flash-anyway case.

TOPPING DX5 II and DX1 II remain outside the normal v0.3 output selector pending separate physical hardware validation.
