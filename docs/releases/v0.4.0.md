# EQ Library v0.4.0

v0.4.0 is a focused Black Pearl update that adds a safe, explicit way to return the DAC's current EQ slot to flat without creating a fake library preset.

## What's new

- Adds **Reset EQ to flat** to My EQs when TRN Black Pearl is the active output and Direct Flash is enabled.
- Places **Connect/Connected** and **Reset EQ to flat** together in the compact Black Pearl control row.
- Keeps Reset disabled until the DAC is connected.
- Requires confirmation before any reset write.
- Operates on the Black Pearl's currently active EQ slot rather than inventing a separate slot selector.
- Overwrites all 10 hardware PEQ bands with zero-gain flat settings, then latches and saves the slot.
- Removes only the playback-gain adjustment previously tracked as applied by EQ Library, preserving later independent user volume changes.
- Uses fail-safe ordering: the EQ slot is flattened and persisted before EQ Library restores its tracked playback-gain attenuation.
- Keeps reconstruction filter, gain mode, amplifier topology, balance, microphone settings, and other unrelated DAC controls outside the reset path.

Reset is a **device action**, not an EQ preset. It does not appear in EQ Library, General EQs, Favorites, saved My EQs entries, or exported preset files.

## Validation

The reset device/DSP implementation was qualified on a Pixel 9 with a TRN Black Pearl using exact signed candidate commit `15f220bd055a2aec49c0cb97c16acbd43ac588da` on 2026-09-06.

Before the hardware pass, that candidate passed Android unit tests, lint, debug/release assembly, CodeQL, signed-beta alignment/signature verification, and the pinned permanent release-certificate check. The focused hands-on pass confirmed:

- disconnected/connected Reset enablement;
- confirmation and Cancel-without-reset behavior;
- all 10 bands reset flat in the current slot;
- active-slot preservation and persisted flat state;
- restoration of EQ Library-applied playback-gain attenuation exactly once;
- no playback-gain change when EQ Library had no tracked adjustment;
- preservation of a later independent user volume change;
- no observed change to unrelated DAC settings.

Controlled mid-transfer failure injection was not exercised on hardware; automated domain tests cover PEQ-transfer failure, final gain-write failure, and retry-safe tracked-gain state.

The final v0.4.0 source differs from the hardware-qualified device/DSP commit only by version and release/documentation metadata. The controlled GitHub release workflow rebuilds/tests/signs the exact published source and verifies the pinned permanent signing identity before publication.

## Install / upgrade

Download the signed `EQ-Library-v0.4.0.apk` asset from this GitHub Release and install it on Android 8.0 / API 26 or newer.

The application ID remains `com.weekssa.opraeqforuapp`, versionCode is 4, and v0.4.0 uses the same permanent Android signing identity as v0.1.0–v0.3.0. Existing installations should upgrade in place without uninstalling or clearing app data.

## Everything from v0.3 remains

v0.4.0 retains the source-agnostic EQ Library foundation introduced in v0.3, including output-specific My EQs collections, OPRA/AutoEq/community/qualified-source catalog handling, General EQs, explicit new-EQ review without silent selection, Hide/Unhide, personal Equalizer APO / AutoEq PEQ import, recovery-only export controls, SAF ownership tracking, UAPP/ToneBoosters conversion, and Black Pearl Direct Flash with non-cumulative playback-gain handling.
