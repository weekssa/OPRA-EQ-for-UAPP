# EQ Library v0.5.0

**Published:** 2026-09-09  
**Android:** 8.0 / API 26 or newer  
**Release asset:** `EQ-Library-v0.5.0.apk`

v0.5.0 is the largest output-system update so far. It expands EQ Library from a small set of output paths into a unified, source-agnostic output framework, improves finite-hardware adaptation, adds new app and DAC targets, and completes a Modern Android Development-style architecture refactor without changing the canonical EQ source model.

## Highlights

### More output choices

Selectable outputs are grouped as **Hardware DACs**, **Apps**, and **Universal formats**.

New and expanded output paths include:

- **TOPPING Tune** — standard AutoEq-style parametric `.txt` import with a 10-band target.
- **EasyEffects** — Equalizer APO-style parametric text, up to the declared target limit.
- **Equalizer APO** — parametric configuration text.
- **AutoEq / Equalizer APO Parametric** — portable universal parametric text.
- **AutoEq GraphicEQ** — portable 127-point GraphicEQ text.
- Existing **USB Audio Player PRO / ToneBoosters**, **Poweramp / Poweramp Equalizer**, and **Wavelet** paths remain available.

The active output remains an operating context only. Switching outputs changes My EQs membership, conversion/fidelity, export behavior, and hardware controls without hiding valid canonical EQs from the library.

## Better finite-hardware EQ adaptation

TRN Black Pearl, FiiO JA11, and stock-firmware JCALLY JM12 now use one deterministic finite-hardware response adapter.

For supported source filters, EQ Library:

1. preserves an exactly representable source as **Exact**;
2. preserves the same filter structure when only native target rounding is required and reports it as **Optimized**;
3. otherwise fits the **complete source response** to the target band budget and requires fixed response-error gates;
4. returns **Not suitable** when a safe, faithful target representation cannot be produced.

Canonical source bands and metadata remain unchanged. The independent UAPP/ToneBoosters contract still uses its established first-10 source-priority behavior because that is a separate format requirement.

## TRN Black Pearl improvements

Black Pearl file export and Direct Flash now consume the same shared 10-band device representation.

- Profiles over 10 source bands are adapted from the complete source response instead of simply taking the first 10.
- Native rounding, full-response fitting, and generated playback headroom are reported distinctly from true Exact preservation.
- Flash confirmation uses the same final plan that the transaction writes, so displayed fidelity, gain, and warnings cannot disagree with the device write.
- Ordinary Optimized adaptation uses the normal **Flash** action. **Flash anyway** is reserved for an actual hardware caution, such as a protocol-encodable filter gain outside the currently validated listening range.
- Black Pearl `.txt` export uses the verified pyBlackPearl `PK / LS / HS` peak/shelf syntax and preserves the true derived preamp. Third-party importer limits are disclosed instead of silently changing the preset.
- **Reset EQ to flat** remains available with its qualified fail-safe gain-restoration behavior.

**Hardware status:** TRN Black Pearl is qualified for the v0.5 path. The Pixel 9 regression covered connection, Cancel/no-write, Exact Flash, Optimized complete-response Flash, full power-cycle persistence, Reset-to-flat persistence, and the explicit out-of-validated-range caution path.

## FiiO JA11 and JCALLY JM12

v0.5.0 includes implemented Direct Flash paths for:

- **FiiO JA11** on normal FiiO firmware — five-band hardware PEQ, global EQ gain, Apply/Save/readback flow, and Reset EQ to flat.
- **JCALLY JM12** on stock firmware — five-band hardware PEQ, readback verification, tracked EQ Library playback-gain adjustment, and Reset EQ to flat.

Both Direct Flash toggles are **OFF by default**, and Add/Save never automatically writes hardware.

**Hardware status:** JA11 and JM12 remain **Hardware validation pending** because the physical test units were not available before this release. Their inclusion is not a hardware-qualified claim. Stock JM12 power-cycle persistence is also not claimed.

No firmware update, bootloader, cross-flash, or unverified JA11/JM12 preset-file format is included.

## TOPPING Tune

TOPPING Tune is now a selectable **Apps** output using standard AutoEq-style parametric text and a 10-band target.

EQ Library uses complete-response fitting when a source cannot fit the 10-band target directly and does not silently clamp an out-of-range source preamp. Because TOPPING's public documentation does not establish downstream hardware storage quantization after import, v0.5.0 conservatively reports TOPPING Tune output as **Optimized** rather than claiming unproven Exact downstream fidelity.

## Android architecture and reliability

v0.5.0 completes an internal Modern Android Development-style refactor intended to improve maintainability and lifecycle reliability while preserving DSP, conversion, and device behavior.

- `MainActivity` is the lifecycle/platform boundary.
- `EqLibraryViewModel` owns immutable screen state.
- A manual composition root constructs platform-backed dependencies.
- Repositories use narrower injected contracts instead of retaining Activity/Context responsibilities.
- USB hardware sessions survive ordinary configuration changes until the ViewModel is actually cleared.
- Transient selections and pending export UI state expected to survive Activity recreation use saveable state.
- SAF ownership lookup distinguishes a genuinely missing exported document from a temporary provider/permission lookup failure, preventing transient access errors from being mistaken for deletion.

The detailed architecture and invariants remain documented in `docs/ARCHITECTURE.md` rather than duplicated in user-facing release material.

## Install / upgrade

Download `EQ-Library-v0.5.0.apk` from the v0.5.0 GitHub Release and install it on Android 8.0 / API 26 or newer.

The application ID remains `com.weekssa.opraeqforuapp`, versionCode is `5`, and v0.5.0 uses the same permanent Android signing identity as prior releases. Existing installations should upgrade in place without uninstalling or clearing app data.

## Everything from v0.4 remains

v0.5.0 retains the source-agnostic EQ Library foundation: output-specific My EQs, canonical OPRA/AutoEq/community/qualified-source catalog handling, General EQs, explicit new-EQ review without silent selection, Hide/Unhide, personal Equalizer APO / AutoEq PEQ import, safe Storage Access Framework ownership/currentness handling, UAPP/ToneBoosters conversion, and qualified TRN Black Pearl Direct Flash/Reset behavior.
