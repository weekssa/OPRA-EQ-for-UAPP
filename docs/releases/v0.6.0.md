# EQ Library v0.6.0

## Highlights

- Adds **My DAC** with a shared, ViewModel-scoped hardware session across My EQs, My DAC, and EQ Library.
- Adds TRN Black Pearl current-EQ inspection, response graph, local editing with verified Apply, Personal EQ capture, Reset EQ to flat, and the qualified EQ Library Restore defaults flow.
- Keeps My EQs device/output-agnostic. Save/Add is separate from Export and Flash.
- Adds strict app-owned export recovery under **Needs attention** without scanning arbitrary external storage.
- Standardizes My DAC operation feedback with a stable DEVICE header and shared bottom Snackbar states for Applying, verification/reconnect, success, and failure.
- Keeps the architecture capability-driven so additional hardware can reuse the same session, state, and feedback contracts.
