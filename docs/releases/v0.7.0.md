## What v0.7 adds

v0.7 adds the exact qualified SIMGOT EW300 DSP cable to the existing capability-driven My DAC architecture. The product path uses one authoritative DAC session and provides:

- five-band direct-Hz **Peak** EQ readback and local editing;
- the shared response graph with active-band markers and a 0 dB reference;
- truthful Flat / exact saved match / ambiguous exact match / Unknown state presentation without curve-similarity source attribution;
- Review → Apply, guarded Flash from the existing My EQs / EQ Library flow, Peak-only Personal EQ capture, and Reset EQ to flat;
- manual EQ/DEVICE Refresh through the existing authoritative session;
- current-versus-last-read freshness, reconnect/final-readback feedback, and accessible non-color status text; and
- a compact DEVICE surface showing only evidence-backed read-only playback/global-gain state, active Peak-band count, and connection freshness.

The exact product capability boundary remains evidence-gated. Register `0x66` is qualified as playback/global-gain state used by guarded EQ transactions and restoration, but the evidence does **not** establish a safe independent user-facing volume-control contract. No standalone EW300 volume, DAC-filter, gain-mode/PGA, amplifier/output-topology, balance, microphone-gain, UAC-switching, firmware-update, routing, or factory-default control is exposed. Those capabilities remain **insufficient evidence**, not automatically unsupported. Firmware/bootloader/erase/calibration/recovery/cross-flash work remains out of scope.

## Shelf-source handling

EW300 native readback, capture, editor, Apply, Flash, and Reset remain Peak-only. Source EQs may still contain low/high shelves. The target adapter now treats those shelves as immutable source filters, evaluates the complete canonical response, and derives a deterministic five-Peak approximation only when the existing RMS and maximum-error gates pass. The result is labeled **Optimized approximation**; a profile that cannot meet the gates remains **Not suitable** rather than being silently altered or truncated.

The shelf regression corpus covers representative OPRA, AutoEQ, community/general, strict text import, Personal EQ, and captured-DAC paths, including low shelf, high shelf, mixed shelves plus Peaks, over-budget input, deterministic repeated output, canonical immutability, headroom behavior, and an explicit unsupported-filter failure. The historical shelf problem is explained by the older adapter requiring source filter families to be natively supported; the current representation-v3 path separates source-response compatibility from the EW300's Peak-only native control surface.
