# v0.7.1: Canonical Favorite resolution

This patch fixes canonical Favorites for catalog EQs whose effective catalog
product uses a retained legacy product identity. Favorites now resolve across
the current canonical headphone catalog source kinds while preserving the
selected canonical profile, revision, acoustic fingerprint, and source
references.

The correction changes compatibility product and vendor IDs only after the
effective catalog proves the exact alias and the displayed product and vendor
exist. Invalid, stale, ambiguous, or mismatched selections continue to fail
closed.

This is a library identity and persistence fix. It does not change EQ values, source-feed parsing, DAC protocols, or hardware behavior.

## Verification scope

The regression matrix covers all current canonical headphone catalog source
kinds and three headphone products. `DEVICE_CAPTURE` and `PERSONAL_IMPORT`
remain in their separate local saved-EQ flows. Source-specific feed parsers are
not independently revalidated by this resolver matrix.
