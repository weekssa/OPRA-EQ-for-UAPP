# EQ Library v0.7.2

v0.7.2 is a stabilization release focused on reliable startup and safer EQ response handling.

## Improvements

- Large cached EQ catalogs load from disk without first copying the complete catalog into a large in-memory string.
- Hardware EQ adaptation checks high-Q response peaks with a denser frequency sweep before generating headroom or accepting a fitted result.
- Device-specific fits that miss the complete response quality limits now fail closed instead of being reported as ready.
- EW300 persistence qualification stops before the first hardware write if its local recovery checkpoint cannot be saved.
- Invalid or missing imported filter gain values are rejected instead of being silently treated as 0 dB.

## Compatibility and scope

- The app package remains `com.weekssa.opraeqforuapp`; this update uses the existing signed Android application identity and supports Android 8.0 / API 26 and newer.
- Hardware identity matching, support authorization, and USB protocol encoding are unchanged. EW300 persistence qualification now stops before its existing write path if the local recovery record cannot be saved. This release adds no DAC support claim and does not add live audio control inside USB Audio Player PRO.
- Privacy behavior, catalog sources, attribution, and offline storage behavior are unchanged.

## Upgrade

Install the signed APK from the [EQ Library GitHub Releases page](https://github.com/weekssa/OPRA-EQ-for-UAPP/releases) over an existing installation to preserve its local app data. Verify the downloaded APK against the published SHA-256 file. Android may ask you to allow installation from the browser or file manager you used to download the APK.
