# EQ Library v0.8.0 beta

This prerelease modernizes the EQ Library navigation and core library workflows while keeping the v0.7.2 DAC transaction and EQ-processing boundaries.

## What changed

- Three persistent roots: My EQs, EQ Library, and Settings. Supported DAC access is contextual and does not add a permanent root tab.
- Separate connected-device context and selected EQ output target, with distinct Saved Headphones, General EQs, and Personal EQ ownership.
- Direct headphone model search, explicit General EQ selection, and a profile detail view with provenance, response preview, fit, and technical information.
- Staged Personal EQ import: Input, Parse, Describe, Review, and Save. Large drafts are kept in app-private temporary storage during state restoration.
- A UAPP export review and completion message that explains the user must import exported ToneBoosters XML in USB Audio Player PRO.
- Reorganized Settings and formatted What's New release notes.
- Fixed light and dark palettes, responsive layouts, large-text support, and full filter values in screen-reader band labels.
- Improved D-pad navigation across root tabs, profile saving, staged Personal EQ import, My DAC review, export review, and recovery controls. The conditional safe-gain action now scrolls into view as it receives focus from the Q field.
- Improved recovery after an interrupted optional Black Pearl EQ reset. The app asks you to refresh DEVICE and does not replay reset steps after state restoration.
- Disconnected JA11 values remain visible as historical data, with editing disabled until a fresh hardware read succeeds.

## Compatibility and limitations

- Package identity remains `com.weekssa.opraeqforuapp`; this beta uses versionName `0.8.0-beta` and versionCode `10` so it upgrades over v0.7.2.
- No DAC support, USB command, identity authorization, hardware session, DSP acceptance rule, or canonical EQ value was added or changed by this UX release.
- EQ Library prepares files and explicit hardware operations. It does not activate EQ or route Android audio inside USB Audio Player PRO.
- The Black Pearl C05-C qualification was a read-only identity/session, EQ/DEVICE read, and attached-navigation check. Class B remains; this beta adds no new DAC support claim.
- v0.8.0-beta is a prerelease, not the stable/latest release. Stable v0.7.2 remains latest and continues to be returned by the app's stable-release update metadata.

## Installation and upgrade

Download [the signed v0.8.0 beta APK](https://github.com/weekssa/OPRA-EQ-for-UAPP/releases/download/v0.8.0-beta/EQ-Library-v0.8.0-beta.apk) from the [v0.8.0 beta prerelease page](https://github.com/weekssa/OPRA-EQ-for-UAPP/releases/tag/v0.8.0-beta). The APK can be installed over v0.7.2 to retain local app data. Verify the downloaded APK using `EQ-Library-v0.8.0-beta.apk.sha256`. Android may ask you to allow installation from the browser or file manager used to download the APK.
