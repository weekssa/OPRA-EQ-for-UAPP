# EQ Library v0.8.0

EQ Library v0.8.0 updates the library, saved-EQ, and export workflows while preserving the qualified DAC and EQ-processing behavior.

## What's new

- My EQs, EQ Library, and Settings are the three persistent app destinations. Supported DAC access stays contextual.
- Connected hardware and the selected EQ output target are presented separately. Saved headphone EQs, General EQs, and Personal EQs have distinct ownership.
- Headphone browsing includes direct model search, explicit General EQ browsing, and profile details with source information, response preview, fit, and technical data.
- Personal EQ import has clear input, parse, description, review, and save steps, and can recover long drafts after an interruption.
- UAPP/ToneBoosters export has a review and completion message. Import the exported file in USB Audio Player PRO to use it there.
- Settings and What's New are easier to scan. Layouts support larger text and varied screens; filter values are available to screen readers, and keyboard/D-pad navigation covers the main workflows.
- If a Black Pearl EQ reset is interrupted, the app asks you to check the current device state and never repeats the reset automatically. For a disconnected FiiO JA11, previous EQ values are labeled as historical until the app reads the current values again.

## Compatibility

The package remains `com.weekssa.opraeqforuapp`. Stable versionCode 11 advances the signed v0.8.0-beta versionCode 10. The release keeps the v0.7.2 DAC identity and transaction boundaries, USB reconnect behavior, DSP acceptance rules, canonical EQ values, and saved-EQ membership. It adds no DAC support claim and does not control live audio inside USB Audio Player PRO.

## Install and upgrade

Download the [signed v0.8.0 APK](https://github.com/weekssa/OPRA-EQ-for-UAPP/releases/download/v0.8.0/EQ-Library-v0.8.0.apk) from the [v0.8.0 stable release](https://github.com/weekssa/OPRA-EQ-for-UAPP/releases/tag/v0.8.0). Verify its bytes with [EQ-Library-v0.8.0.apk.sha256](https://github.com/weekssa/OPRA-EQ-for-UAPP/releases/download/v0.8.0/EQ-Library-v0.8.0.apk.sha256). You can install it over v0.7.2 or v0.8.0-beta to keep local app data. Android may ask you to allow installation from the browser or file manager used to download the APK.
