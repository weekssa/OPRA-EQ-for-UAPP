# EQ Library v0.8.1

EQ Library v0.8.1 improves session handling for FiiO JA11 operations that reset or re-enumerate the USB connection.

## What's new

- Mic and UAC changes wait for the previous USB session to end, then verify the result through a fresh session. An uncertain write is not repeated automatically.
- JA11 EQ write workflows select and verify User 1 before sending EQ data. After a saved profile causes a reconnect, the app verifies the final state through the fresh session without replaying writes.
- Connection handling rejects ambiguous supported-device candidates and does not use VID/PID alone as identity.

## Compatibility and scope

The package remains `com.weekssa.opraeqforuapp`. This update uses versionName `0.8.1` and versionCode `12`, advancing stable v0.8.0 code `11`. It adds no DAC model or public support claim. It does not promise same-unit continuity when the device provides no usable serial or general PEQ retention after true power loss. Built-in program and volume remain runtime controls; no Save behavior is added to them.

## Install and upgrade

Install the signed v0.8.1 APK over v0.8.0 to retain local app data. Verify the APK against the SHA-256 file published with the release. Android may ask you to allow installation from the browser or file manager used to download the APK.
