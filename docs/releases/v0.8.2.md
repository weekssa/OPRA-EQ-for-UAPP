# EQ Library v0.8.2

EQ Library v0.8.2 corrects the FiiO JA11 EQ screen remaining blank after a saved profile reconnects the DAC.

## What's new

- My EQs keeps its saved items and open headphone detail when Automatic output briefly changes during reconnect. Target-specific compatibility and export currentness still update for the selected output.
- An authorized JA11 Flash finishes final verification and refreshes EQ and DEVICE state even if its initiating screen is left. Closing the owning app session still cancels its work.

## Compatibility and scope

The package remains `com.weekssa.opraeqforuapp`. This update uses versionName `0.8.2` and versionCode `13`, advancing v0.8.1 code `12`. The existing JA11 control, native EQ, persistence and device-identity boundaries remain those recorded in the current capability matrix.

## Install and upgrade

Install the verified signed v0.8.2 APK over v0.8.1 to retain local app data. Compare the APK with its supplied SHA-256 before installing. Android may ask you to allow installation from the browser or file manager used to open the APK.
