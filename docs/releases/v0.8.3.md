# EQ Library 0.8.3

EQ Library 0.8.3 adds an explicit defaults workflow for FiiO JA11 volume and EQ program settings.

## JA11 volume and program defaults

- Volume and EQ program editors stage selections locally. Cancel or dismiss leaves the device unchanged.
- **Apply** changes the current session only.
- **Set as Default** reviews the volume/program pair and requires confirmation before the app starts its verified microphone reconnect sequence. Success requires the selected pair and original microphone state to be verified after reconnect.
- This operation does not use native EQ Save, change UAC, or write EQ-band/gain data. User 1 EQ data is not changed by this flow.

The separate `0.8.3-beta.1` candidate completed the bounded owner phone test on a FiiO JA11 reporting firmware 2.20. The owner subsequently reported that the identified candidate and all other manual tests passed. On that test profile, the verified post-power-cycle readback showed volume 19 and Classic, with Mic On and UAC 2.0. The owner accepted the evidence limits: application operation counts are not USB bus captures, and no native EQ Save, UAC change, or EQ-band write was used. The available report did not compare User 1 EQ data for the tested Off/Classic programs or capture unique serial identity. This exact-candidate result does not establish bus-level counts, User 1 preservation, same-unit continuity, or a general JA11 firmware contract.

## Compatibility and installation

- Stable package: `com.weekssa.opraeqforuapp`, versionName `0.8.3`, versionCode `14`.
- Android 8.0 / API 26 or newer.
- Install over EQ Library 0.8.2 to keep local app data. The isolated beta uses a different application ID and is not the stable install package.
- The release is signed with the project's pinned permanent Android release identity. Verify the downloaded APK using the published SHA-256 checksum.
- No Google Play account, EQ Library account, cloud account, analytics, or telemetry is required.

The signed APK, checksum, signer report, candidate manifest, and release provenance are published with the release. See the [public release checklist](../PUBLIC_RELEASE_CHECKLIST.md) for the exact immutable candidate and post-publication verification record.
