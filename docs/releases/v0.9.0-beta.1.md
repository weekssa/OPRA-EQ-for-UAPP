# EQ Library v0.9.0-beta.1

NOT PUBLISHED. These notes describe a development candidate; official signed bytes, hardware qualification and publication approval are pending. Public stable/latest remains v0.8.3. This beta does not authorize stable v0.9.0.

## Changes

- User1 Set as Default uses fresh exact unchanged EQ staging, Apply and one native Save, preserving microphone state without toggles. Qualification across actual unplug/replug is pending.
- Other programs retain the explicitly confirmed microphone round trip. The app does not automatically switch to that fallback after an uncertain native save.
- Defaults failures now reach the UI and changed EQ readback cannot be reported as verified. Stale, ambiguous, incomplete and inexact native state is rejected.
- Existing five-band EQ/gain, volume/program, mic/headset, UAC, available firmware/sample-rate readback, Flash/editor/Reset and explicit defaults remain within the approved regression scope.

## Limitations and attribution

FAST-LL, FAST-PC, Slow-LL, Slow-PC and NON-OS were each researched in three passes. Source packet generation is established, but independent exact-JA11 reply/runtime/persistence evidence is insufficient. All five remain disabled; this is not proof that the hardware lacks them. Arbitrary native program Save payloads remain unqualified. Historical bank loss/restoration limits are preserved.

Reference-first analysis used Ircama/ja11-config at affddff6c9808c33ce8b35b0b9759ff0d7f6e405 (EUPL-1.2), compiled only its configuration target, and compared independently adapted protocol facts without incorporating its source into this Apache-2.0 app. Existing OPRA codec evidence remains authoritative where reference arithmetic conflicts. See [reference evidence](v0.9.0/REFERENCE_EVIDENCE.md).

## Installation, upgrade and rollback

Do not distribute a development artifact as this release. After approval, install only the checksum-verified APK signed by the pinned production signer, package com.weekssa.opraeqforuapp, versionName 0.9.0-beta.1, code15. An in-place update from stable code14 must preserve the populated library and settings; exact official-signed clean/upgrade checks remain pending after main-only signing.

Retain an exported copy of personal EQs before any owner-selected rollback. Android ordinarily rejects downgrading code15 to code14; uninstall/reinstall may remove local data. Do not promise seamless rollback or reset app/device data automatically. The existing v0.8.3 public artifact remains available with its recorded checksum/signer. No firmware change is included.
