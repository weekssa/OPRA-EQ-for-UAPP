# EQ Library v0.9.0-beta.4

**Status: beta prerelease, not a stable release.** v0.9.0 remains the latest stable release.

- Package: com.weekssa.opraeqforuapp
- Version: 0.9.0-beta.4 / versionCode 21
- Installs over v0.9.0 and keeps local app data
- No Google Play account, cloud account, analytics or telemetry

## Highlights

### FiiO JA11 Tuning (Ellyn)

My DAC -> DEVICE gains a Tuning (Ellyn) toggle. It writes the two KT config registers the community
"Ellyn" firmware changes, verifies each readback, and persists on write across a genuine power cycle:

- Register 0x3A: 4 (stock) -> 0 (Ellyn)
- Register 0x3B: 0x0D (stock) -> 0x0C (Ellyn)

The toggle applies and reverts between the two known sets. It does not write register 0x5B, the USB
identity register (2972:0102 vs 31B2:2003); the transport refuses that address and a regression test
asserts it is never a tuning parameter.

### DEVICE page redesign

- "Device settings" header with Refresh; no explanatory sub-line.
- Audio: Device volume, EQ program, Tuning (Ellyn), Startup settings.
- Startup settings shows "Not saved" with a Save action after a change, "Saved" after the save, and
  makes no claim on a fresh connect.
- Volume uses a slider; microphone and USB Audio Class confirmations are one line each.
- Automatic reconnect re-reads device state and clears stale tuning state on disconnect.

### Persistence model

Runtime edits apply immediately. Volume and EQ program are session-only until Set as Default (command
0x19), which commits the startup store and briefly re-enumerates USB. The tuning registers are written
directly to non-volatile config and need no save.

## Evidence and limits

- Tested on one Pixel 9 and one JA11 at firmware 2.20. The audible result is an owner report; it is not
  an acoustic measurement.
- The tuning values are derived from the community "Ellyn_GP" firmware image, which differs from the
  official V2.2 image in seven bytes. Their meaning beyond these registers is not independently
  documented.
- Only the tested firmware is qualified. The control is present on all builds; other firmware and
  other units are not qualified.
- A wrong register write has already re-badged one unit to 31B2:2003; recovery required reflashing the
  official V2.2 image. The identity register is now hard-blocked.
- Full register map, protocol and measurements: docs/FIIO_JA11_PROTOCOL_NOTES.md.

## Not included

- Firmware update, flashing, bootloader or cross-flash paths.
- A restart-free save for volume/program; the FiiO 0x19 Save remains the only exposed path.
- JA11 digital reconstruction filters remain unsupported on the tested firmware.
