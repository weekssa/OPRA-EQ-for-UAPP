# EQ Library v0.9.0

**Status: public stable release.** Published on 2026-11-01 after the approved source, official signing, exact-artifact promotion, clean-install and upgrade gates passed.

## Highlights

- **FiiO JA11 saved settings now work.** The selected built-in EQ program (Vocal, Classic, Bass, User 1, Off) and device volume can be saved as JA11 startup defaults and survive genuine unplug and replug. The save uses the JA11 native preset-specific transaction, preserves the active EQ and microphone setting, and never cycles the microphone.
- **Runtime and saved state are distinct.** Runtime changes apply immediately and remain session-only until Set as Default; a verified save is labelled as saved for startup.
- **Digital filters are not part of v0.9.0.** The JA11 firmware tested (2.20) does not expose a reconstruction-filter control through the official vendor interface, so the control is not shown. The research is preserved for a future version.

## FiiO JA11 details

- Set as Default writes the active five-band bank and global gain, applies once, saves once, and verifies the result, tolerating one brief re-enumeration.
- The JA11 may disconnect briefly while saving; the app re-reads and verifies afterward.
- Unplugging the JA11 restores its saved startup program and volume; unsaved runtime changes revert.
- The custom User 1 bank and global gain are preserved; no flat curve or helper preset is substituted.
- No microphone or UAC changes are made by the defaults transaction.

## Known limitations

- JA11 digital reconstruction filters are not exposed by the official vendor implementation on firmware 2.20; the control is deferred. See the complete [digital-filter research handoff](../research/FIIO_JA11_DIGITAL_FILTER_RESEARCH_HANDOFF.md).
- Persistence was physically qualified on one Pixel 9 and one JA11 at firmware 2.20; see J035 for the exact test and limits.
- The qualified defaults transaction re-stages the active bank for built-in programs; a smaller vendor-aligned sequence remains a future optimisation pending its own qualification.

## Upgrade and installation

- v0.9.0 is the public stable/latest release. The verified installation flow passed both clean installation and an in-place upgrade from public v0.8.3; the upgrade preserves app data.
- The official release workflow signed the APK and promotion published that exact verified candidate. See the [release artifact record](../release-engineering/v0.9.0-stable/ARTIFACTS.md) for checksums and provenance.
