# OPRA EQ dependency security assessment

## Critical alert assessment

- **#35, GHSA-574f-3g2m-x479 / CVE-2025-14813, Bouncy Castle 1.79.** The advisory concerns GOST 28147 CTR mode counter wrapping, which can repeat keystream material under the affected conditions. The vulnerable version is present on the AGP build-tool classpath, so it is a real local build-tool exposure. It is absent from `releaseRuntimeClasspath`. Pinning the Bouncy Castle modules to 1.85 clears both this and the newer BC advisory below.
- **#49, GHSA-c4c3-7fpv-j4q5 / CVE-2026-75595, Netty 4.1.93.Final.** The advisory concerns SNI routing fallback when a TLS ClientHello is fragmented. The described impact depends on a server using SNI-selected contexts as the only mTLS authorization gate and a permissive fallback context. The application does not ship Netty; the affected version is pulled by Android Unified Test Platform tooling. The GitHub advisory classifies this as critical. Its impact analysis limits mTLS bypass to deployments where per-SNI contexts are the only gate, the default context is permissive, and no application-level peer-certificate check exists; the advisory records attack requirements as present.
- **#50, GHSA-9pwp-9qqc-pr26 / CVE-2026-8763, Bouncy Castle 1.79.** The advisory concerns X.509 name-constraints bypass for trailing-dot rfc822Name/URI values. The affected component is on the AGP build-tool classpath, not in the app runtime. Pinning to 1.85 clears it.

## Scope and method

The GitHub alert API returned **56 open Maven alerts** on 2026-10-20: 3 critical, 22 high, 28 moderate, and 3 low. Each alert is listed below, including repeated alerts for different advisories against the same component. GitHub reports `settings.gradle.kts` as the manifest for all rows; that file only declares repositories and is not treated as a dependency path.

I resolved the actual Gradle configurations and compared them with the GitHub Dependency Graph SBOM (created 2026-10-20 23:58:17 UTC). `releaseRuntimeClasspath` and `debugRuntimeClasspath` contain none of the alerted coordinates. Bouncy Castle, Commons Lang, jose4j, JDOM, and Apache HttpClient appear in AGP build tooling. Netty appears in Unified Test Platform build/test configurations. Guava and jsoup appear in Android instrumentation-test runtime. The Kotlin Gradle plugin is a build plugin. Thus this alert set does not establish vulnerable code in the shipped app APK; it does include actionable build/test supply-chain exposure.

The proposed Gradle constraints are limited to the buildscript plugin classpath and dependency configurations of project subprojects. AGP 9.2.0, Gradle 9.4.1, app version 0.8.3/code 14, signing setup, and release configuration remain unchanged. The Kotlin plugin moves to 2.4.21 and KSP to 2.3.12. Kotlin documents KGP 2.4.20 compatibility through Gradle 9.7.0 and AGP 9.3.1; the selected Gradle 9.4.1 and AGP 9.2.0 are within that range, and the 2.4.21/KSP 2.3.12 combination passed the checks below. Alert #1 is left unchanged because the current resolved version is already 4.5.14, beyond its fixed version; GitHub should refresh that graph.
